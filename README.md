# Darevault

![Image of darevault front page](/public/img/image.png)

<p>Whenever me and my friends play truth or dare, it always devolves into one of us searching for "fun dares to do" on chrome. Darevault eliminates this problem by letting users store their own unique dares while on the go. Be it on Android, IOS, MacOS, Linux or basically any other platform, rest assured that any device with an internet connection is capable of running Darevault. When the whole gang is together, Darevault lets you access these stored dares at random, so nobody knows who put in what.</p>

[Demo Link](https://dare-vault.web.app/)

## How it Works

- Make an account using email or one touch sign in with Google.
- Create a new vault.
- Share the Vault ID and name with them and beg them to join.
- Add dares whenever you think of them.
- Start a session when everyone is together

## Technologies Used

- Vue.JS with GSAP, Tailwind and web technologies for the frontend
- Firebase (Firestore, Authentication) for the backend
- Vite for build tools
- Hosted on Firebase Hosting

## Key Learning points

- Got to work with a proper web stack, something I have been putting off for a while.
- Learned basic UI and UX design. Figured out how to practically apply color pallettes to apps without it looking like a circus.
- Learned the techniques used in NOSQL databases and dat modelling as a developer with a SQL background.
- Used modern css techniques such as variables and got familiar with how Tailwind works.
- Practical experience with asyncronous javascript, which took a while to figure out.

---

Overall it was a fun and challenging project by which I was able to familiarise myself with common industry tools and techniques.
